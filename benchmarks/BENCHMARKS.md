# Flora — Benchmark Report (реальный прогон, 2026-08-28)

Все числа получены фактическим запуском чекпоинта
`checkpoints/best-epoch=052-val/pearson_r=0.7278.ckpt` на 40 отложенных
клипах (`scripts/benchmark_flora.py`, GPU, split seed=42 — точное
воспроизведение протокола `train_lightning.py`).

## 4. Протокол

- Сплит: 160 train / 40 val из 200 клипов (`torch.Generator(seed=42)`,
  `random_split` — идентично `train_lightning.py`). Валидационные клипы:
  000407, 000460, 000309, 000056, 000100, 000409, 000364, 000416, 000402,
  000105, 000268, 000405, 000456, 000205, 000062, 000202, 000367, 000354,
  000365, 000358, 000114, 000361, 000164, 000251, 000051, 000451, 000103,
  000450, 000318, 000000, 000106, 000055, 000003, 000201, 000153, 000464,
  000117, 000306, 000154, 000119.
- Метрика: корреляция Пирсона по каждой из 400 парцелл (chunk-parcellation
  проекта) по всем парам (клип, TR), затем среднее.
- Линейный базлайн: ridge-регрессия concat(text 384, audio 384, video 640)
  → 400 парцеллов, λ=10⁻², обучена на тех же 160 клипах (в духе линейного
  базлайна TRIBE v2).
- Карты точности: per-parcel r → атлас Schaefer-400 → `vol_to_surf` на
  fsaverage5 (nilearn 0.14; поверхности FreeSurfer-derived).

## 6. Что НЕ измерялось (честно)

- Метрика — согласие студент–учитель (дистилляция), не сырый фМРТ.
- p-value / FDR / шумовой потолок — не вычислялись.
- Абляции компонентов (HRF-свёртка, MoE, гейтинг, FiLM) — не запускались.
- Сравнение с TRIBE v2 на рис. 01 — разные протоколы (Algonauts fMRI vs
  KD-валидация), не сопоставимо напрямую.
